# 执要 Agent — 品牌标识规范 v3（纯黑白）

## 品牌故事

> **圣人执要，四方来效。**
> 用户是执要的圣人，AI 是四方来效的助手。

## 设计原则（依据通用 logo 设计方法论）

简洁 · 可缩放（16px→300px 均可读）· 黑白成立 · 不撞常见图标 · 有意义（图形即故事）。

## 方案 D1 几何构造（128 网格）

- 外框：圆角方 x=14..114，rx=16，stroke 8
- 合符折线：M 64,6 → (54,38) → (74,54) → (54,70) → (74,86) → 64,122（两道锯齿）
- 右半实心黑（clip 到圆角方内），左半留白
- 点睛：白半黑点 (40,40) r=6；黑半白点 (88,88) r=6（evenodd 镂空，自适应任何背景）
- 图标版：白底（rx=28 圆角方）+ 黑标，标记缩放 0.7

## 色彩

- **纯黑白**：#000000 / #FFFFFF，无任何彩色（参考 ChatGPT 扩展的图标惯例：白底黑标）
- UI 主题：ChatGPT 式纯黑白灰（浅色 #ffffff/#f4f4f4/#0d0d0d，暗色 #212121/#303030/#ececec）

## 字体（字标）

- 「执要」：宋体系衬线（Noto Serif SC / STSong / SimSun）
- 「AGENT」：现代无衬线 + 3px 字距
- 标语：圣人执要 · 四方来效
- UI：Carlito / Calibri / Segoe UI 字体栈（ChatGPT 同款）

## 用法约束

- 黑白不得加入任何彩色；白底用黑标，深底用反白
- 标记最小 16px；不得变形、加投影、改锯齿节奏与点眼位置
