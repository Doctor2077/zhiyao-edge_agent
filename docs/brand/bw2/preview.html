执要 Agent · 纯黑白方案 v2

设计原则：简洁 / 可缩放 / 黑白成立 / 不撞常见图标 / 有意义（四方来效）

方案 D · 合符推荐

虎符一剖为二，合符则四方来效
圣人执要之信物：一半白一半黑，锯齿相合为一印。持符者令出，四方见符而效
16px = 半黑半白的方印，剪影独一无二

方案 E · 司南

执一以定四方
磁针指一，四方来效：环 + 针 + 针眼。圣人定方向，AI 循向而行
16px = 环中一针；风险：像指南针

方案 F · 圆规

执规矩以正四方
定圆心（执要），画圆周（来效）：规的两足 + 铰点 + 足弧 + 圆心一点
16px = A 形 + 点；风险：像字母 A / 圆规工具
