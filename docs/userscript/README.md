# 执要 Agent · 用户脚本版（脚本猫 / Tampermonkey）

`zhiyao-agent.user.js` —— 「执要 Agent」的用户脚本版本：页面右下角悬浮球 + 侧边浮层面板（Shadow DOM 隔离，不受页面样式影响）。

## 与扩展版的差异

| 能力 | 扩展版 | 用户脚本版 |
|---|---|---|
| 打开方式 | Edge 侧边栏 | 页面右下角悬浮球 / 脚本菜单 |
| 读页面对话 | ✅ | ✅ |
| 操作网页（逐步确认 + 自动模式） | ✅ | ✅ |
| 整页翻译替换 / 去广告 / 技能 | ✅ | ✅ |
| 会话历史、日志、定时任务 | ✅ | ❌（浏览器 API 限制） |
| 数据存储 | chrome.storage | 脚本管理器本地存储 |

## 在脚本猫发布

1. 打开 https://scriptcat.org/ → 登录 → 「+」新建脚本
2. 把 `zhiyao-agent.user.js` 全文粘贴进去（保留顶部 `==UserScript==` 元数据块）
3. 保存后即可在自己的浏览器生效；发布到商店需在「脚本设置」里填写名称/描述/分类（阅读、工具）后提交审核
4. 也可让用户通过脚本链接安装（脚本猫支持从 URL 安装）

## 使用

1. 打开任意网页 → 点右下角悬浮球
2. 「设置」标签 → 选服务商预设（默认 DeepSeek）→ 填 API Key → 点「测试连接」
3. 回到「对话」提问；或点快捷技能胶囊（网页总结 / 翻译页面 / 去除广告 / 代码解读）

## 请求失败的排查（重要）

用户脚本的网络请求受脚本管理器的跨域策略约束，报错时要看**具体信息**：

| 现象 | 原因 | 处理 |
|---|---|---|
| `测试连接` 显示 HTTP 401 | Key 错误或额度不足 | 到服务商后台核对 Key |
| HTTP 429 / overloaded | 服务商限流或过载 | 稍后再试，或换模型 |
| 网络错误 / CORS / 请求失败 | 脚本管理器跨域权限未放行 | 脚本猫 → 该脚本设置 → 允许跨域；元数据已声明 `@connect` 各服务商域名与 `*` |
| 一直转圈 | Base URL 不通（如需代理的服务商） | 换国内可直连的服务商（DeepSeek 等） |

脚本内已实现：先尝试 `fetch` 流式，失败自动回退 `GM_xmlhttpRequest`，两条路都失败才会报错。
