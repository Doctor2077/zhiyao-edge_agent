关于执要

Edge 侧边栏里的网页 AI 助手：自带 OpenAI 兼容的 API Key，即可与当前网页对话，让 AI 动手操作网页，一键整页翻译，下载媒体资源，还能定时检查页面变化。所有数据只在你与你的模型服务之间流转，不经过任何服务器。

  • 整页翻译直接替换（刷新即恢复）
