# 隐私政策（Privacy Policy）

> 执要 Agent（Zhiyao Agent）Edge 浏览器扩展 · 最后更新：2026-09-10
> 本政策同时以中文和英文提供；如有出入，以中文为准。
> This policy is provided in Chinese and English; in case of discrepancy, the Chinese version prevails.

## 一、我们收集什么（What We Collect）

**我们不收集任何数据。** 本扩展没有服务器、没有账号体系、没有遥测或埋点。

**We collect nothing.** This extension has no server, no account system, no telemetry or analytics.

## 二、数据去向（Where Data Goes）

- 页面内容：仅在以下时刻、由**你自己的浏览器**直接发送给你自己配置的模型服务商（OpenAI 兼容 API）：① 你在侧边栏发送消息时；② 你创建的定时任务触发时。发送对象完全由你配置，开发者无法看到或中转这些数据。
- Page content is sent **directly from your browser** to the model provider you configured, only when you send a message in the panel or when a scheduled check you created fires. The developer never sees or relays this data.

## 三、本地存储（Local Storage）

以下数据仅保存在你的浏览器本地（`chrome.storage.local` / `chrome.storage.session`）：

- 你配置的模型服务商信息与 API Key（Key 可设为仅本次会话，关闭浏览器即清除）
- 对话历史、已安装技能、设置、日志、定时任务
- 这些数据不离开你的设备；卸载扩展即全部删除。

The following stay in your browser only: your provider configs and API keys (keys can be session-only), chat history, installed skills, settings, logs, and scheduled tasks. None of it leaves your device; uninstalling removes it all.

## 四、权限使用（Permission Use）

本扩展申请的权限仅服务于扩展功能本身：读取当前页面（供对话/操作）、在用户确认后操作页面、下载用户确认的直链媒体、定时唤醒与系统通知。详见商店列表中的权限理由。

All requested permissions serve the extension's own features only (page reading, confirmed page actions, confirmed media downloads, scheduled checks with notifications). See the permission justifications in the store listing.

## 五、第三方服务（Third-Party Services）

- 模型服务：由用户自选并自带 Key，受该服务商自身条款约束
- 本扩展不接入任何第三方统计、广告或追踪服务
- Model providers: chosen by you, subject to their own terms. This extension integrates no third-party analytics, ads or tracking.
